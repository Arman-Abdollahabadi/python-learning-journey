## 📁 Contents

| Folder  | What's inside                                                |
| ------- | ------------------------------------------------------------ |
| `games` | Small terminal games to practice logic, loops and conditions |

## 🎮 Games

| #   | Game                                             | Concepts practiced                                                                              |
| --- | ------------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| 1   | [Number Guessing](games/number-guessing)         | `random`, `for` loop, `if/elif/else`, `break`, `for...else`, f-strings                          |
| 2   | [Rock Paper Scissors](games/rock-paper-scissors) | lists, `random.choice()`, `while` input validation, `and`/`or` conditions, `break`/`exit()`, score counting |

## ▶️ How to run

Make sure Python 3 is installed, then run any game in a terminal:

    python games/number-guessing/number_guessing.py
    python games/rock-paper-scissors/rock_paper_scissors.py
